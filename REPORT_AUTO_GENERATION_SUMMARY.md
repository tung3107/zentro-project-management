## 🗄️ Database Schema

### Reports Table

```sql
CREATE TABLE reports (
  report_id INT AUTO_INCREMENT PRIMARY KEY,
  project_id VARCHAR(50) NOT NULL,
  report_type ENUM('project_progress', 'team_performance', 'task_deadline', 'general') NOT NULL,
  report_name VARCHAR(255) NOT NULL,
  start_date DATETIME NOT NULL,
  end_date DATETIME NOT NULL,
  filters JSON DEFAULT NULL,
  statistics JSON NOT NULL,
  ai_analysis TEXT DEFAULT NULL,
  file_url VARCHAR(500) DEFAULT NULL,
  is_auto_generated BOOLEAN DEFAULT FALSE,
  generated_by VARCHAR(35) DEFAULT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,

  FOREIGN KEY (project_id) REFERENCES projects(project_id) ON DELETE CASCADE,
  FOREIGN KEY (generated_by) REFERENCES users(user_id) ON DELETE SET NULL
);
```

**Fields Explained:**

- `report_id`: Unique identifier
- `project_id`: Which project this report belongs to
- `report_type`: Type of report (progress/team/deadline/general)
- `report_name`: Human-readable name (e.g., "Tiến độ dự án - 01/11/2025 đến 25/11/2025")
- `start_date`, `end_date`: Date range for the report
- `filters`: Additional filters applied (JSON)
- `statistics`: Calculated stats (tasks, completion %, etc.)
- `ai_analysis`: AI-generated insights (Markdown text)
- `file_url`: Path to saved JSON file
- `is_auto_generated`: `true` if generated by scheduler, `false` if manual
- `generated_by`: User ID who generated it (NULL for auto-generated)
- `created_at`: When the report was created

## ⏰ Scheduled Task Configuration

### Cron Schedule

```javascript
// Runs every day at 6 PM (18:00)
cron.schedule("0 18 * * *", async () => {
  // Generate reports for all active projects
});
```

### Schedule Format

```
┌───────────── minute (0 - 59)
│ ┌───────────── hour (0 - 23)
│ │ ┌───────────── day of month (1 - 31)
│ │ │ ┌───────────── month (1 - 12)
│ │ │ │ ┌───────────── day of week (0 - 6)
│ │ │ │ │
0 18 * * *
```

### What Gets Generated

- **Report Type**: `project_progress` (default for daily auto-reports)
- **Date Range**: Yesterday to today
- **Projects**: All projects with `status = 'Active'`
- **Generated By**: `null` (indicates auto-generated)

## 🔄 Report Generation Flow

### Manual Generation (User-Initiated)

```
1. User clicks "Tạo báo cáo" in UI
   ↓
2. Frontend sends POST /api/v1/reports/generate
   ↓
3. Backend generates report with user's filters
   ↓
4. Save to database with generated_by = user_id
   ↓
5. Save JSON file to /uploads/reports/
   ↓
6. Return report to frontend
   ↓
7. Display in UI
```

### Auto Generation (Scheduled)

```
1. Cron job triggers at 6 PM
   ↓
2. Find all active projects
   ↓
3. For each project:
   - Generate yesterday → today progress report
   - generated_by = null
   - is_auto_generated = true
   ↓
4. Save to database
   ↓
5. Save JSON file
   ↓
6. Log success/errors
```

## 🔍 How It Works

### Auto-Report Generation Process

1. **Cron Job Triggers**

   - Every day at 18:00 (6 PM server time)
   - Checks all projects in database

2. **Project Filtering**

   - Only processes projects with `status = 'Active'`
   - Skips inactive/completed projects

3. **Report Generation**

   - **Type**: Always `project_progress` for auto-reports
   - **Date Range**: Yesterday → Today (24 hours)
   - **Filters**: Project-specific, no user filter

4. **Data Collection**

   - Queries tasks, sprints, members, comments
   - Calculates statistics
   - Determines task status based on status names

5. **AI Analysis**

   - Sends data to Gemini AI
   - Generates Markdown-formatted insights
   - Falls back to basic analysis if AI fails

6. **Database Storage**

   - Creates record in `reports` table
   - Sets `is_auto_generated = true`
   - Sets `generated_by = null`

7. **File Storage**
   - Saves report data as JSON file
   - Stores file URL in database
   - Files organized by project and date

## ⚙️ Configuration Options

### Customize Schedule Time

Edit `server/scheduler/reportScheduler.js`:

```javascript
// Change from 6 PM to 9 AM
cron.schedule("0 9 * * *", async () => {
  // ...
});

// Run every 6 hours
cron.schedule("0 */6 * * *", async () => {
  // ...
});

// Run only on weekdays at 6 PM
cron.schedule("0 18 * * 1-5", async () => {
  // ...
});
```

### Customize Report Type

```javascript
// Change default auto-report type
const filters = {
  reportType: "general", // Instead of "project_progress"
  // ...
};
```

### Customize Date Range

```javascript
// Last 7 days instead of yesterday-today
const today = new Date();
const lastWeek = new Date(today);
lastWeek.setDate(lastWeek.getDate() - 7);
```
